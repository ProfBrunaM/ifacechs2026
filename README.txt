# Projeto Integrador (IFA) — Site

## Estrutura

- `index.html` — estrutura do site
- `style.css` — cores, layout e responsividade
- `script.js` — interações
- `img/` — coloque aqui a logo e as fotos dos projetos

## Onde alterar

No `index.html`, procure pelos comentários:

1. **ÁREA DE ALTERAÇÃO 1: LOGO**
   - Coloque a logo em `img/logo-colegio.png`.

2. **ÁREA DE ALTERAÇÃO 2: APRESENTAÇÃO**
   - Altere o texto de apresentação.

3. **ÁREA DE ALTERAÇÃO 3: NOTÍCIAS / LINKS**
   - Substitua os endereços `https://exemplo.com/link...`.
   - Troque `Link 1`, `Link 2`, etc. pelos nomes reais.

4. **ÁREA DE ALTERAÇÃO 4: GALERIA DE PROJETOS**
   - Troque as fotos.
   - Altere nome, descrição e equipe.
   - Para criar mais projetos, copie um bloco `project-card`.

## Fotos

Use estes nomes inicialmente:

- `img/projeto-1.jpg`
- `img/projeto-2.jpg`
- `img/projeto-3.jpg`
- `img/projeto-4.jpg`

Se quiser usar outros nomes, altere o `src` correspondente no HTML.

## Como abrir

Abra o arquivo `index.html` no navegador.

O site foi feito para funcionar tanto em computadores quanto em celulares.
